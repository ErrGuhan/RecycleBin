# Brand Assets Directory

Place official Bisleri brand assets in this directory:
- `logo.svg`: Official Bisleri primary logo (dark/colour for light backgrounds)
- `logo-white.svg`: Official Bisleri white monochrome logo (for dark backgrounds)
- `favicon.png`: High-resolution square icon (192x192 / 512x512)

Until official files are provided, the portal uses the accessible typographic placeholder `BrandLogo.tsx` with `--brand-primary-strong` (#00796B) and the official initiative subtitle per `AGENTS.md`.
